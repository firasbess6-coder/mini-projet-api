Fonctionnement :
Ce mini-projet, réalisé par Firas Bessioud et Mohamed Yacine Ayari, est une API REST développée avec Node.js, Express.js et MongoDB. Il permet aux utilisateurs authentifiés de gérer leurs projets et leurs tâches, avec des fonctions de recherche et de tri. L’authentification utilise JWT et les accès dépendent du rôle : user ou manager. Seul le manager peut affecter des tâches aux utilisateurs.
